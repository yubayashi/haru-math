🍕 分数って「分けること」だよね

ピザを半分に分けたら、1人分は 12。
4つに分けたら、1人分は 14。
ここまでは分かるよね。

↑ 10マスのうち5マス塗った = 12

ルール: 塗ったマスの数がそのまま小数になる。
5マス塗った → 0.5。 1マス塗った → 0.1。
このバーをこれからずっと使うよ。

① 1/2 = 0.5 = 50%

まずは一番よく使う数。半分。

10マスのうち5マス → 0.5

10マスのバーのちょうど半分は5マス。
だから 1/2 = 0.5。

じゃあ、% はどうやって出すの？
%（パーセント）は「100のうちいくつ」という意味。
100マスあったら、半分は50マスだよね。だから 50%。

12 = 0.5 = 50%
💡 覚え方: 半分 = 5割 = 0.5 = 50%。
「半分」って聞いたら、0.5と50%がセットで出てくるようにしよう。
② 1/4 = 0.25 = 25%

次は4分の1。ポルトガル語では um quarto（ウン・クアルト）。

10マスのバーだと、1/4はぴったり分けられない（10÷4 = 2.5になっちゃう）。
だから、もっと細かい 100マスのグリッド（10×10）で見てみよう。

10×10 = 100マスのグリッド
赤い線で4つに分けた。青い部分が 14 = 25マス

100マスを4つに分けると、1つのブロックは25マス（5×5）。
100マスのうち25マスだから → 0.25 → 25%。

14 = 0.25 = 25%
💡 覚え方: 4つに分けた1つ = 25%。
25円玉4枚で100円、と同じ考え方！
③ 3/4 = 0.75 = 75%

さっき 1/4 = 25マスだったよね。
じゃあ 3/4 は？ → 25マス × 3 = 75マス！

10×10 = 100マスのグリッド
4ブロックのうち3ブロック（75マス）が 34

4つのブロックのうち3つを塗った。
ほとんど全部だけど、右下のブロック1つだけ空いてるね。

34 = 0.75 = 75%
✅ 1/4と3/4はセットで覚えよう:
14 = 25% → 34 = 25% × 3 = 75%
14 = 0.25 → 34 = 0.25 × 3 = 0.75
1/4が分かれば3/4も分かる！

この仕組みは次のレッスンでもっと使うよ！
⑤ 1/100 = 0.01 = 1%

最後は一番小さい数。100マスのうちたった1マス。

10×10 = 100マスのグリッド
100マスのうち、左上の1マスだけ → 0.01

すごく小さいね。これが 1%。
「100個のうちの1個」と考えれば分かりやすい。

1100 = 0.01 = 1%
💡 バーとグリッドの関係:
10マスのバーの 1マス = 0.1
100マスのグリッドの 1マス = 0.01
グリッドの方が10倍細かい！
📋 まとめ — この5つを覚えよう！

分数、小数、%は全部同じ数の違う書き方。
この5セットが頭に入っていれば、テストでも日常でもすぐ使える。
