通分 (mesmo denominador)
分母をそろえると比べられる！
例: 2/3 と 3/4 → 8/12 と 9/12
約分 (simplificar)
分子と分母を同じ数でわる
例: 6/10 → (÷2) → 3/5
fração → decimal
分子 ÷ 分母
例: 3/4 = 3 ÷ 4 = 0,75
decimal → %
× 100
例: 0,75 × 100 = 75%
よく使う分数 ↔ 小数 ↔ %
1/2 = 0,5 = 50% 1/4 = 0,25 = 25% 3/4 = 0,75 = 75% 1/5 = 0,2 = 20% 1/10 = 0,1 = 10%
